# PaPop Support

Static support and privacy pages for PaPop.

## Pages

- `index.html` - support center landing page
- `support.html` - technical support URL for App Store metadata
- `privacy.html` - privacy policy URL for App Store metadata

## Deployment

Enable GitHub Pages for this repository and publish from the `main` branch root.

Use these URLs after GitHub Pages is active:

- Support URL: `https://erha19.github.io/papop-support/support.html`
- Privacy Policy URL: `https://erha19.github.io/papop-support/privacy.html`

## Before Submission

Replace `support@papop.app` with the production support inbox if needed.
